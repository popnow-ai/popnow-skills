# PopNow effects catalog

Every effect in `effects.json`, grouped by category. Popular effects are marked with a star. Each row names the model the effect runs on; the exact price of one run comes from `scripts/effects.py quote <slug> --image <photo>`. Samples and the website version of each effect: `https://popnow.ai/effects/<slug>`.

Snapshot: 2026-10-19, 143 effects. Two-person effects from the website (they need two photos) are not included.
